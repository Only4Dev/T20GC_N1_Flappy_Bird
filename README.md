T20GC_N1_FlappyBird

My first game created as part of the 20 Games Challenge.

Features
-Keyboard, Mouse and Touch controls
-High Score persistence using PlayerPrefs
-Game States (Waiting, Playing, Game Over)
-Simple sound effects
-WebGL support

Controls
-Space
-Left Mouse Button
-Touch

Built With
-Unity 6
-C#
-Input System
-TextMeshPro

This project helped me practice:

*Rigidbody2D physics
*Prefabs
*UI
*Scene Management
*Game Architecture
*PlayerPrefs
*Audio
*State Machines
